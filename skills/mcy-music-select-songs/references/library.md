# Церковная библиотека песен

Источник по умолчанию — [Музыкальные ресурсы](https://docs.google.com/spreadsheets/d/1YelbhnrZTGDl1uHC8oG43-Y9XXjEagWbEDdSTrflzkc/edit?gid=0#gid=0).
Идентификатор таблицы: `1YelbhnrZTGDl1uHC8oG43-Y9XXjEagWbEDdSTrflzkc`.
Если пользователь явно указал другую библиотеку для текущего запроса, используй ее.

Ни тексты песен, ни выгрузка каталога не входят в пакет скилла. Их нужно читать
из текущей таблицы, к которой у пользователя и ассистента есть доступ.

## Как найти рабочие данные

Основной лист при создании скилла — **«Библиотека»**, `sheetId = 0`.
Получай его текущее название из метаданных по идентификатору: имя может измениться.
Если листа с этим идентификатором больше нет, найди рабочий каталог по заголовкам,
а при неоднозначности уточни источник. Не выбирай резервную копию вместо него.

Известные вспомогательные листы: «Сборники», «Полезные материалы» и листы
«Библиотека — бэкап …». Они не являются дополнительным текущим репертуаром.
Ссылки на сборники не означают, что все песни из сборников уже есть в библиотеке.
Если появились новые рабочие песенные листы, проверь их заголовки и включи
их песни в общий просмотр. Не включай архивы и копии повторно.

На основном листе первая строка содержит заголовки. Известная схема:

| Столбец | Заголовок | Назначение |
| --- | --- | --- |
| A | # | Номер песни, не номер строки Google Sheets |
| B | Название | Точное название |
| C | Текст | Полный текст для смыслового анализа |
| D | Референс | Ссылка на запись |
| E | Ключ | Тональность |
| F | Темы | Подсказки для тематики |
| G | Библейский текст | Библейская ссылка, указанная в каталоге |
| H | Папка | Ссылка на материалы песни |
| I | ПВ | Дополнительный номер из каталога; для подбора необязателен |

Это ориентир, а не неизменная схема: каждый раз сверяй заголовки. Для первичного
чтения заголовков подойдет `A1:I3` после подтверждения существующих границ.
Далее читай нужные столбцы до актуальной нижней границы сетки, при необходимости
порциями. Не используй постоянный диапазон из прошлого запроса. Если инструмент
возвращает значения с удаленными пустыми строками в конце диапазона, учитывай
границы запрошенного диапазона и его явный признак усечения; короткий ответ сам
по себе не означает, что непрочитанных песен ниже нет.

Номера в столбце A могут быть заполнены заранее далеко ниже последних песен.
Определяй наличие песни по названию или тексту. Различай номер песни и позицию
строки, особенно после сортировки, вставки строк или обработки порциями.

## Получение настоящих ссылок

Обычное чтение значений может вернуть «YouTube ↗» или «Drive ↗» вместо URL.
Для выбранных песен запроси данные соответствующих ячеек с `hyperlink`,
`textFormatRuns` и `userEnteredValue`; URL может быть обычным значением,
формулой `HYPERLINK` или ссылкой в форматированном тексте. Не угадывай адреса.

Ссылку на строку можно построить из проверенных идентификаторов таблицы и листа
и фактического номера строки: к адресу `/edit` добавь
`?gid=<sheetId>&range=<ячейка_названия>`. При известной схеме ячейка названия
в строке r — `Br`; после перестановки столбцов используй актуальный столбец.
Сначала убедись, что в этой строке находится выбранная песня.

## Доступ и инструменты

Предпочитай подключенные инструменты Google Sheets/Drive. Сначала получи
метаданные, затем ограниченные диапазоны значений; данные гиперссылок нужны
только для итоговых кандидатов. При раздельных параметрах передавай имя листа
и диапазон ячеек отдельно; в полной A1-записи заключай имена листов в кавычки.

Если подключенных инструментов нет, используй доступный авторизованный способ
чтения или актуальную выгрузку, явно предоставленную пользователем для запроса.
Если свежесть выгрузки неизвестна, обозначь это. Не требуй открыть таблицу всем
и не меняй ее настройки доступа. При ошибке доступа сообщи о ней и запроси
нужный доступ или свежую выгрузку; не подменяй библиотеку поиском в интернете.

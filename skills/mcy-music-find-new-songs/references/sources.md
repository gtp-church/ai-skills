На каждом запуске читай весь текущий лист. Сначала узнай границы сетки и заголовки,
затем ограниченными порциями прочитай все строки, не останавливаясь на промежутке.
Определи поля названия/автора, URL и типа по реальной структуре. Не фиксируй буквы
столбцов: их размещение и заголовки могут меняться. Если типы оформлены заголовками
групп, применяй их к строкам только при подтвержденной структуре; при неоднозначности
уточни, как определить тип. До этого не открывай неоднозначные ссылки.

Текущие заголовки — «Источник», «Тип», «Ссылка»; каждый раз сверяй их заново.
Правило владельца: строки с типом **«Приложение» или «Приложения»** неактуальны
и исключаются; в проверенном живом листе используется единственное число.
Названия источников и остальные типы не перечислены здесь намеренно:
состав списка может пополняться. Если у строки несколько реальных ссылок, учти их.
Повторяющиеся источники объедини. Заполнитель вроде «TBA» не является адресом.

Обычное чтение значений может вернуть только подпись гиперссылки. Если URL
не виден, запроси данные ячеек с `hyperlink`, `textFormatRuns`
и `userEnteredValue`; адрес может быть обычным значением или формулой
`HYPERLINK`. Не конструируй URL из названия источника.

Если лист с нужным идентификатором отсутствует, найди реестр по содержимому
и заголовкам, а при нескольких вариантах уточни источник.

## Как исследовать разные источники

Используй подключенные инструменты соответствующего сервиса, когда они дают
нужный доступ; иначе доступный авторизованный способ чтения. Ошибка одного способа
не доказывает отсутствие песен в источнике. Не меняй права доступа или содержимое.

При временной транспортной ошибке повтори запрос чтения отдельно один раз.
Если ошибки возникли при параллельном чтении, дочитай неудавшиеся диапазоны
последовательно; успешные ответы повторять не нужно. При повторной ошибке
обозначь ограничение доступа и сохрани возможность продолжить с этого места,
не помечая такой источник пустым или полностью проверенным.

**Google Drive.** Открой указанную папку или файл. Сначала ищи каталог, оглавление
или таблицу с песнями, затем подходящие материалы. Если обходишь дерево папок,
учитывай подпапки, ярлыки и все страницы выдачи; не зацикливайся на повторных ссылках.
Ограниченный список первых файлов не является всей папкой. Читай подходящие
тексты из документов, таблиц, PDF и нот доступными инструментами. Для PDF с одними
изображениями нужен поддерживаемый способ распознавания; без него текст
не считается прочитанным. Не выгружай всю коллекцию без практической необходимости.

**Сайты.** Пользуйся их каталогом и поиском, переходи на страницы песен, читай
полные тексты и проверяй ссылки на материалы. Если нужен поисковик, ограничивай
поиск текущим источником; сниппет используй только для обнаружения страницы.
Связанные внешние страницы конкретной песни допустимы для проверки ее текста
или материалов, а не для бесконтрольного расширения списка коллекций.

**Каналы.** Определи площадку по ссылке. Используй доступные список публикаций,
поиск, плейлисты и закрепленные каталоги. Открывай исходные публикации песен.
Описание видео не всегда содержит весь текст, а автоматические субтитры могут
искажать слова; сверяй версию и полноту. При невозможности прочитать канал
назови ограничение. Не выводи текст песни из одного названия или прослушивания,
которого фактически не было.

Общий реестр и собственную библиотеку нужно читать целиком при каждом запуске.
Для внешних коллекций проверяй текущий состав и версии отдельных документов,
затем обновляй SQLite по [index.md](index.md). Время изменения корневой папки
не подтверждает неизменность всех вложенных документов. Индекс не заменяет
текущую проверку метаданных и доступности. Если объем коллекции или ошибка
помешали завершить обновление, точно укажи охват; сохраненные старые данные
не считаются подтвержденными на этот запуск.
